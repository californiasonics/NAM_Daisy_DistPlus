# \## Running the Daisy sketch

# 

# 1\. Install the Arduino IDE.

# 2\. Add STM32 board support: File → Preferences → Additional boards manager URLs:

# &#x20;  `https://github.com/stm32duino/BoardManagerFiles/raw/main/package\_stmicroelectronics\_index.json`

# &#x20;  then install \*\*STM32 MCU based boards\*\* from the Boards Manager.

# 3\. Install \*\*DaisyDuino\*\* from the Library Manager. 

# 4\. Board settings: \*\*Generic STM32H7 Series\*\*, board part number \*\*Daisy Seed\*\*,

# &#x20;  upload method \*\*STM32CubeProgrammer (DFU)\*\*.

# 5\. Open the ino file, put the Daisy in bootloader mode

# &#x20;  (hold BOOT, tap RESET), and upload.
